# Locale — Tax & Cost Snapshot

An early, separate MVP for exploring estimated federal income tax and public housing-cost statistics by location.

## Run locally

```bash
npm run serve
```

Open `http://localhost:4174`.

## Current coverage

- Functional 2026 federal tax estimate for three filing statuses
- Four demonstration ZIP-code snapshots
- Explicit source-year and methodology language
- State and local tax coverage intentionally marked unavailable until authoritative rule adapters exist

The housing figures are demonstration values for interface development and must be replaced by Census/HUD ingestion before publication.
